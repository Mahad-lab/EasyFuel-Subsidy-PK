# EasyFuel Subsidy PK

EasyFuel is an independent, open-source utility that helps people in Pakistan format SMS messages for the government's petrol relief scheme. Enter your vehicle and CNIC details to generate a registration message, or prepare a fuel-token request. Your information is processed in your browser; you choose whether to send the generated message using your device's messaging app.

EasyFuel is not an official government service and is not affiliated with the Government of Pakistan, NADRA, or any Excise department. Eligibility, quotas, token availability, and subsidy terms are set by the official scheme and can change. Confirm the current requirements through official channels before relying on them.

## Development

Requires Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Build and preview the production site:

```bash
pnpm build
pnpm preview
```

The site is built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).
